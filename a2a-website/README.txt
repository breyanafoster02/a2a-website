A2A Solutions website (static, for Vercel)

Deploy: put these files at the root of your GitHub repo (replacing the old site), push, and Vercel redeploys.
Settings: Framework Preset "Other", no build command, output directory blank.

Before launch:
1. Contact form: create a free Formspree form (sends to bfoster@a2asolutions.org), then in contact.html set data-endpoint="https://formspree.io/f/YOURID". Until then the form opens an email draft instead.
2. Tier I details marked CONFIRM in the blueprint (term, setup fee, systems, whether bookkeeping is included) are not on the page yet.
3. Confirm the $30B and $2M results are cleared for public posting.
4. Confirm SBA's certification search and SAM.gov both show WOSB.
